## Couple web application

- App Router routes live in `src/app`; authenticated routes are in `src/app/(private)` and authentication routes are in `src/app/(auth)`.
- Reusable application shell and UI primitives live in `src/components`.
- Feature UI lives in `src/features`; Supabase browser/server setup and shared hooks live in `src/lib`.
- Global styling and responsive rules live in `src/app/globals.css`. Self-hosted font declarations live in `public/fonts.css`.
- Reuse `@couple/api`, `@couple/domain`, `@couple/theme`, TanStack Query, Zod, and Lucide React before adding another dependency.
- Keep the login screen's current layout and colors isolated from private-app theme changes.
- Private application changes must remain usable with the desktop sidebar and the four-item mobile bottom navigation.
- Preserve Vietnamese diacritics in source and use the self-hosted fonts declared in `public/fonts.css`.

## Verified commands

Run these from `fe/`:

- `corepack pnpm --filter @couple/web dev`
- `corepack pnpm --filter @couple/web typecheck`
- `corepack pnpm --filter @couple/web lint`
- `corepack pnpm --filter @couple/web build`
- `corepack pnpm test`
- `corepack pnpm test:e2e`

The Playwright command requires the local-only values generated by `scripts/prepare-e2e.ps1` and a running local Supabase instance.
